## Estimator choices (where the Amendment left room)

- Kendall tau-b via scipy (`auto`: exact when no ties, else asymptotic); a constant series gives tau 0, p 1.
- Wilcoxon signed-rank via scipy (exact when no ties/zeros; zero differences dropped).
- Bootstrap: resample reference functions of each snapshot (found-arrays), B draws, seeded per snapshot; Delta bootstrap = earliest minus head draws; median-Delta interval = 2.5/97.5 percentiles of the per-draw median over lineages.
- P3 Holm p: max of the two one-sided bootstrap tail fractions at -0.10 / +0.10 (with +1 smoothing); P3 met = interval inside AND Holm p < 0.05.
- Partial correlation: partial Spearman on ranks (linear residuals on rank of log(eligible_snapshot)).
- Plan membership by plan_kind column or by (port, sha) in the plan file; f=0 snapshots are kept when usable and otherwise listed as underpowered.
- Pure-C: lang_c >= 0.9 and |lang_c, lang_cpp, lang_other - head| < 0.10 each. Pruned filter: pruned token set equal to head's.
- Head = latest usable snapshot; earliest = earliest usable.
- H8.3(a): self-origin survival surv(s0 -> head) read from self_origin.csv; lambda from S0=1 fits of the other lineages' self-origin curves over all usable snapshots (median); rank-regression baseline maps the leave-one-out rank of the R1 head survival to an age by quantile interpolation.
- H8.3(b): see section 8.
